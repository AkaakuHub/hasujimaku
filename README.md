生成画像には、8×8ブロックの輝度DCT係数へ量子化方式で透かしを埋め込みます。モデルのダウンロードや画像の外部送信は行いません。

平坦なブロックと透明なブロックを除外し、RGBの変化は各チャンネル最大3階調に収まります。ブロックごとの固定署名との相関を集計して検出します。元画像や個別の画像IDは不要です。画像の輪郭や模様が少なく、128ブロックを確保できない場合は生成をエラーにします。

`pnpm test`で、JPEG品質60（4:2:0）、256色パレット減色（ディザあり・なし）、JPEGと減色の連続適用を実際のコーデックで検証します。テスト画像での検出と未埋め込み画像の誤検出防止を確認するもので、任意の画像や減色方法での検出を保証するものではありません。縮小・切り抜き・回転、および旧方式で生成された画像の検出は対象外です。

処理の根拠は、[DCT領域の量子化によるJPEG耐性の研究](https://ietresearch.onlinelibrary.wiley.com/doi/10.1049/el.2015.2522)と[画像の情報量に応じたQIM埋め込みの研究](https://ieeexplore.ieee.org/document/6654837/)です。パレット減色への耐性は、この実装の圧縮・減色テストで評価します。
